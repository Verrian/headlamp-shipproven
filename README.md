# ShipProven for Headlamp

**Autonomous code, proven before it ships.**

[ShipProven](https://shipproven.com) is autonomous software engineering that
can't ship unsafe code. Every change its AI agents produce must survive the
same production pipeline a human engineer's would — and win the approval of a
consensus of independent models — before it can merge.

This [Headlamp](https://headlamp.dev) plugin shows that work inside your
cluster: every Plan, the pipeline of steps it runs, and the agents, pull
requests and gates behind each one.

## Installing

In Headlamp, open **Plugin Catalog**, search for **ShipProven**, and click
**Install**. Then open your cluster; ShipProven appears in the sidebar.

The plugin reads the ShipProven resources already in your cluster and needs
nothing else set up. On a cluster without ShipProven the section is simply
empty.

For an in-cluster Headlamp, point the Helm chart's plugin manager at the
Artifact Hub package, or download the tarball named in the latest
`*/artifacthub-pkg.yml` and unpack it into `/headlamp/plugins`.

## What is in here

Only Artifact Hub metadata: one `<version>/artifacthub-pkg.yml` per release,
each pointing at a published, versioned, checksummed tarball. These files are
regenerated by the ShipProven release pipeline; the plugin source is not
public.

To see ShipProven on your own codebase, book a technical walkthrough at
[shipproven.com](https://shipproven.com).
